# ابدأ من هنا — OpenWorldGame Merged v0.2

## ما الذي تحتويه الحزمة؟

هذه حزمة مشروع مصدر Unreal Engine 5.8 مدمجة من:

- `OWG_Android_Starter_v0.1.zip`: الأساس البرمجي الذي يحتوي على مشروع Unreal C++ أولي، شخصية ثالثة المنظور، مركبة Rigid-Body تجريبية، واجهة UMG لمس، حفظ محلي، ومشهد Greybox.
- `OpenWorldGame_scaffold.zip`: اختبارات C++ مستقلة وأدوات تدقيق ومساعدات منطقية قابلة لإعادة الاستخدام.
- `OPEN_WORLD_GAME_MASTER_SPEC_AR.txt`: المواصفات الرئيسية الكاملة، محفوظة كما وردت.

**الحالة:** مشروع مصدر أولي مدمج، وليس لعبة مكتملة ولا APK. لم يتم تشغيل Unreal Engine أو إنشاء حزمة Android في بيئة الدمج.

## طريقة فتح المشروع على Windows

1. ثبّت إصدار Unreal Engine 5.8.
2. فك ضغط مجلد `OpenWorldGame_Merged_v0.2` إلى مسار قصير.
3. افتح `OpenWorldGame.uproject` باستخدام Unreal Engine 5.8.
4. اسمح للمحرّك بتوليد ملفات المشروع، ثم ابنِ `OpenWorldGameEditor` عبر toolchain المطابق لإصدار Unreal.
5. افتح المحرر واضغط Play لفحص النموذج التجريبي.
6. بعد نجاح بناء المحرر، جهّز Android SDK/NDK/JDK حسب وثائق UE 5.8 ثم ابنِ Android arm64-v8a.
7. لا تعتبر APK جاهزاً حتى تثبته على هاتف حقيقي وتختبر التشغيل في وضع الطيران واللمس والحفظ.

## الفحوص المتاحة

من جذر المشروع:

```bash
python3 Scripts/validate_project.py
python3 Scripts/audit_files.py
python3 -m unittest discover -s Tests -v
bash Scripts/run_host_tests.sh
```

الاختبارات الأربعة تفحص سلامة الملفات والمنطق المستقل فقط. لا تحل محل UnrealHeaderTool أو UnrealBuildTool أو اختبار الهاتف.

## التحكم الأولي

### لوحة المفاتيح

- `WASD`: تحريك الشخصية أو تسارع/توجيه المركبة.
- `Mouse`: تدوير الكاميرا.
- `Space`: قفز للشخصية / فرامل للمركبة.
- `Left Shift`: ركض.
- `E`: دخول السيارة أو الخروج منها.
- `F5`: حفظ محلي.
- `F9`: تحميل آخر حفظ.

### لمس Android

توجد عصا Unreal الافتراضية مع أزرار UMG للأوامر الأساسية. لا تزال مواقع الأزرار ومناطق الأمان وتعدد اللمس بحاجة إلى اختبار على هواتف فعلية.

## ما تم تحسينه في الدمج

- اعتماد مسار Module C++ القياسي `Source/OpenWorldGame/OpenWorldGame.cpp` مع إزالة النسخة المكررة.
- دمج أدوات اعتماد المطوّر وتحويل السرعة وقياس FPS ومنطق الدخول والخروج.
- ربط قياس FPS بنافذة من أزمنة الإطارات، مع إبقائه مستقلاً عن حد الإطارات المختار.
- إضافة تحقق مسافة/سرعة/مقعد قبل دخول السيارة.
- فحص أربع جهات محتملة للنزول وإبقاء اللاعب داخل السيارة عند فشل تبديل التحكم.
- إضافة اختبارات مستقلة للحفظ والإصدارات القديمة والتلف والقيم غير الصالحة.
- دمج تقارير الفحص وسجل الأصول ومصفوفة أجهزة Android وCI.

## حدود مهمة

- المركبة الحالية نموذج قوى على جسم صلب، وليست Chaos Vehicle مكتملة.
- لا توجد أصول `.uasset` أو `.umap` نهائية؛ البيئة Greybox تُنشأ من أشكال Unreal الأساسية عند التشغيل.
- لا توجد شخصية Mesh أو حركات نهائية أو موسيقى أو أصوات أو مشهد سينمائي.
- لا يوجد عالم مدينة/ريف فعلي أو World Partition/Streaming أو NPC/مرور/مهام.
- ملف `Source/OpenWorldGame/SaveSystem/OWSaveData.h` نموذج حفظ محمول مستقل لاختبار التحقق والترحيل؛ الحفظ داخل اللعبة حالياً يستخدم `USaveGame` في `OWGSaveGame.h`.
- مساعدات حد FPS المستقلة تُختبر على المضيف؛ واجهة اللعبة الحالية تعرض Auto/30/40/60 فقط، ولا تدّعي كشف Refresh Rate الجهاز أو دعم 90/120.
- Unreal 5.8 وAndroid SDK/NDK وADB غير متوفرة في بيئة الدمج؛ لم يتم Compile أو Package أو Install أو Playtest.
