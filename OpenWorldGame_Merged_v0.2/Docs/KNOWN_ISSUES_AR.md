# المشكلات والقيود المعروفة — الدمج v0.2

1. **حرج — لم يتم بناء المشروع بالمحرك:** لم يُشغّل UnrealHeaderTool أو UnrealBuildTool أو Editor؛ احتمال ظهور أخطاء توافق C++/UHT ما زال قائماً حتى بناء المشروع على UE 5.8.
2. **حرج — لا APK:** لا يوجد Android Shipping APK، ولم يحدث تثبيت أو اختبار Offline على هاتف.
3. **عالٍ — المركبة ليست Chaos Vehicles:** هي جسم صلب واحد مع قوى تحكم تقريبية؛ العجلات المرئية لا تملك محاكاة تعليق/تماس مستقلة.
4. **عالٍ — لا أصول نهائية:** البيئة مكعبات وأشكال Engine Basic Shapes؛ لا نموذج سيارة أو Mesh شخصية أو حركات أو خرائط نهائية.
5. **عالٍ — لا عالم مفتوح فعلي:** لا World Partition/Streaming/HLOD/PCG أو مدينة/ريف مكتملين.
6. **عالٍ — لا سلوك عالم:** لا NPC أو مرور أو مهام أو طقس/ليل/نهار متكامل أو صوت نهائي.
7. **عالٍ — اللمس غير مختبر:** يجب اختبار UMG والـVirtual Joystick ومناطق الأمان وتعدد اللمس ومقاسات الشاشات على أجهزة حقيقية.
8. **متوسط — FPS cap محدود:** واجهة المصدر تعرض Auto/30/40/60 فقط. لا يوجد كشف فعلي لمعدل تحديث شاشة Android أو اعتماد كامل على `SupportsFramePace`/`SetFramePace`؛ 90/120 ليست مفعلة.
9. **متوسط — حفظ اللعبة يحتاج Runtime QA:** يوجد `USaveGame` محلي، لكن حفظ/تحميل حالات القيادة والخروج وإعادة التشغيل لم تُختبر في المحرك.
10. **متوسط — ملف Portable Save ليس runtime save:** `SaveSystem/OWSaveData.h` نموذج مستقل لاختبارات CRC والترحيل؛ لا تستبدل به `USaveGame` دون تصميم ترحيل وربط متكامل.
11. **متوسط — الإضافات:** لا يوجد Plugin إضافي مفعّل في `.uproject`. Chaos Vehicles وEnhanced Input لم يتم دمجهما؛ لا تفعّلهما فقط لأن scaffold أشار إليهما.
12. **منخفض — لا شعار/موسيقى/أيقونة نهائية:** شاشة المطور نصية؛ لا توجد صور أو صوتيات خارجية ولا رخص أصول تحتاج مراجعة حالياً.
13. **خطر بيئة — أدوات ناقصة:** يلزم Unreal Engine 5.8، toolchain متوافق، Android SDK/NDK/JDK، ثم ADB وهاتف فعلي لإكمال بوابة الإصدار.
