# سجل الأصول الناقصة — Merged v0.2

لا تتضمن الحزمة أي ملفات `.uasset` أو `.umap` أو صور أو سيارات أو شخصيات أو أنيميشن أو موسيقى أو مؤثرات صوتية خارجية. المشهد الحالي Greybox يُنشأ من أشكال Unreal الأساسية عند التشغيل.

| الأصل المطلوب | الموجود | الناقص |
|---|---|---|
| شخصية بشرية | كلاس CharacterMovement وكاميرا | Mesh وهيكل عظمي وحركات مرخصة |
| سيارة | جسم Rigid-Body صندوقي وأربع عجلات شكلية | موديل مرخص وإعداد Chaos Vehicle وتعليق/عجلات مستقلة |
| مدينة | أرض وطريق وكتل مبانٍ تجريبية | مبانٍ وأحياء وطرق ولافتات وأثاث ومواد مرخصة |
| ريف وطبيعة | لا يوجد محتوى ريفي نهائي | تضاريس ونباتات وصخور وبيوت وخامات |
| صوت | لا توجد ملفات صوتية | موسيقى أصلية/مرخصة ومحرك وخطوات وبيئة |
| هوية مرئية | نص اعتماد المطور داخل UMG | شعار وأيقونة Android وصورة افتتاحية معتمدة |

لا يُضاف أي أصل خارجي إلى Build قابل للتوزيع قبل توثيق رخصته وحالة مراجعته في `Docs/ASSET_LICENSE_MANIFEST.csv`.
